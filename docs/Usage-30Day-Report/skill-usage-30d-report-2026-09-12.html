统计方法

  • Claude Code — 扫描 ~/.claude/projects/**/*.jsonl（近30天 mtime），匹配 Skill 工具调用字段 "skill":"<name>"，精确无歧义。
  • Codex — 扫描 ~/.codex/archived_sessions/ 与 ~/.codex/sessions/（近30天），匹配 exec 命令中读取 skills/<name>/SKILL.md 的痕迹。Codex 没有独立的调用事件，此处统计的是"被模型读取/激活"次数。

  • 命中数是"被当作工具调用参数出现"的次数，不是聊天中提及技能名字的次数，避免误报。
  • 创建日期取自该 skill 目录在 git 历史中的首次提交（git log --follow），用于排除"刚创建、还没到30天统计窗口"的误判——这类 skill 零命中不代表闲置，只是太新。
  • 零命中且已存在满30天的 skill，也不代表永久无用，可能是季节性任务（如 quarterly-review）尚未到触发时机，建议人工复核后再决定下线或归档进 inbox/。
